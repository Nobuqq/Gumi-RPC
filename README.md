# Gumi-RPC
Your multitasking app that lets you run your games and music from one place, with a custom Discord Rich Presence that actually looks like you.
What it does:
1. Game shelf: your games in one launcher. Each game gets its own Discord presence with its art and a Play button.
2. Music player: play your songs, albums and playlists in-app. While a song plays, Discord shows a spinning CD made from the album cover.
3. Themes: make a theme from any picture and the whole app matches it: accent colour, boxes, player, everything. Fonts, colours, neon glow and custom sidebar icons are all yours to change.
4. Mini player: a full-width bar in Music that shrinks to a floating pill everywhere else. Drag the pill anywhere on screen; double-click it to put it back.
5. Up next: right-click any song to play it next, add it to the queue, or add it to a playlist.
6. Ask Gumi: a little tour guide that walks new users through the app the first time it opens.
7. Marketplace (coming soon) — theme packs made by the community, with their own pictures and sounds.

# Download
Grab the latest installer from the [Releases](https://github.com/Nobuqq/Gumi-RPC/releases)
# Discord setup (one time) 
1. Go to https://discord.com/developers/applications click # New Application
2. Copy the Application ID.
3. In Gumi RPC, go to Settings → Discord Application ID and paste it in.
4. Keep the Discord desktop app open while you use Gumi RPC.
That's it — your games and music will show up on your profile.
# Run it from source 
You need [Node.js](https://nodejs.org/en) first. Then, in the folder: 
 - npm install
 - npm start
Make the installer (.exe) with:
- npm run build
# Beta
