CDWhat the spinning CD shows, on Discord and in the app. The two are fully independent.
DeveloperOnly on this dev copy. Showcasing mode swaps the real library for sample content, so a screenshot or a video never shows anyone else’s albums.
UpdatesGumi RPC checks for updates when it opens and downloads them in the background. A new version installs when you restart the app.

Customize

Make Gumi RPC yours: themes, fonts, colours, icons and glow

FontPick your own font file (.ttf / .otf / .woff) and size
Default font
IconsYour custom silhouettes, recoloured here. Games, Music and Settings in the sidebar.
ThemeTap a theme to switch to it. You never have to delete one to change it. The accent colour changes with the theme.
My themesAdd a picture as a theme. The whole interface takes its colours from the picture automatically, and you can change the accent on the card if you like. Best picture ratio is 16:9 (1920×1080). If a picture does not fit, change Fit / Position / Zoom below. Cover fills the box (crops the edges), Contain shows the whole picture.
Sound effectsPick your own sounds for each moment. Hover a row to hear it, and set any volume you like. Volume 0 silences that sound.
